# Transformer-based Neural Machine Translation (NMT) – English to German

This project implements the Transformer architecture (Vaswani et al.) from scratch using PyTorch to perform sequence-to-sequence translation from English to German. It covers all stages including data preprocessing, training, and inference.

---

## 🔍 Project Breakdown

### ⚙️ 1. Transformer Training Pipeline
- Built a full encoder-decoder Transformer using PyTorch.
- Tokenized and preprocessed the English-German corpus using SubwordTextEncoder.
- Implemented custom positional encoding, attention masks, and training loop.

### 📈 2. Inference and Evaluation
- Ran inference on unseen English test sentences.
- Visualized predicted German translations.
- Calculated BLEU score to evaluate performance.
